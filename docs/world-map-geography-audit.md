# География карты: проверка до изменений
Нумерация площадок подтверждена пользователем: по строкам внутри каждого квартала.
Существующие ID сохранены. Новая визуальная раскладка:
01–04 MeikuNeko, PETPOWER, toutes peaux, Koyo;
05–08 КЛИМЫЧ, WALNUT, Ou!borka, Generalim;
09–12 ХОББИЛАБ, Paw Factory, MyMania, NUZHNOE;
13–16 Поле Ягода, МУЛЬТИЗАВРИК, YesMix, RASTVOR.

В PostgreSQL сейчас:
district-1: MeikuNeko, КЛИМЫЧ, Ou!borka, PETPOWER;
district-2: МУЛЬТИЗАВРИК, WALNUT, RASTVOR, Generalim;
district-3: YesMix, Paw Factory, NUZHNOE, toutes peaux;
district-4: ХОББИЛАБ, MyMania, Koyo, Поле Ягода.

Таким образом, экранное расположение можно поменять без изменения IDs, но перенос принадлежности между районами требует миграции. Она должна атомарно переставить 16 строк buildings, обойти временные конфликты UNIQUE(district_id,position), пересчитать unlocked_districts по уже открытым зданиям и обновить seed-каталог. First building, unlocked_buildings, коллекция, сцены, монеты и сохранения модулей не меняются. До согласования серверная принадлежность остаётся прежней; она не подменяется клиентским состоянием.
