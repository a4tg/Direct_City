# CORE POLISH PLAN · Meiku World

План опирается на CORE_GAMEPLAY_AUDIT.md. Каждую задачу можно принять отдельно. Номера P0–P3 обозначают замечания аудита.

1. **Защитить сохранение от перезаписи (P0-01).** Выбрать одну политику записи между вкладками. Начать с воспроизводимого теста «100 монет → покупка за 60 в первой вкладке → свет во второй». Приёмка: после перезагрузки баланс 40, коврик на месте, выбранное состояние света сохранено. Проверить покупку одного предмета из двух вкладок и возврат из фонового режима.
2. **Закрепить совместимость сохранений и расчёт потребностей (P1-04, P3-03).** Добавить фикстуры свежего старта, v0, v1 без покупок, v1 со всеми покупками и повреждённого поля. Определить правило остатка времени. Приёмка: одинаковая длительность даёт одинаковые потери при разных интервалах вызова, пределы отсутствия соблюдаются, корректные поля сохраняются. Цены и награды остаются предметом отдельного решения.
3. **Согласовать пространство комнаты (P1-03, P2-02, P2-03).** Задать якоря зоны пола, миски, игрушки и общего слота сна. Настроить маски и размеры котика в коробке и лежанке. Зафиксировать разрешённую зону перетаскивания. Приёмка: сравнить стартовую и полностью улучшенную комнаты при 320×640, 390×844, 430×932 и 1280×800. Миска доступна для уборки, игрушка не блокирует её, после покупки лежанки отображается только она, при смене обоев пол и опорные точки остаются на месте.
4. **Привязать поведение к завершению движения (P1-01, P1-02).** Зафиксировать правила приоритета кормления, сна, каприза и перенаправления на игрушку. Привязать визуальное положение и эффекты к одной траектории. Приёмка: кормление и сон начинаются у нужного предмета, повторные команды не умножают награды, смена вкладки и reduced motion дают согласованный результат.
5. **Смягчить смену поз (P2-01).** Начать с выравнивания опорных точек на имеющихся PNG и переходов walk → eat, walk → sleep, sleep → idle. При наличии графики подключить цикл походки и игру с мышкой без клубка. Затем уточнить вид опрокинутой премиальной миски. Приёмка: просмотр последовательностей в реальном времени без внезапных скачков размера и слоя; сокращённый вариант с reduced motion.
6. **Улучшить обратную связь (P1-05, P1-06).** Перенести сообщения покупки к карточке, пояснить назначение шкалы дружбы и сообщать, почему кормление или награда временно недоступны. Проверить достижимость первого коврика на чистом сохранении и зафиксировать наблюдение для отдельного решения о балансе. Приёмка: на 320 px игрок видит результат без прокрутки к началу списка и понимает следующее доступное действие.
7. **Измерить нагрузку, затем добавить декоративную полировку (P3-01, P3-02).** Записать исходный профиль при холодной загрузке, первом кормлении, перетаскивании и просмотре магазина. Оптимизировать только выявленные расходы. Приёмка: сравнить объём первой загрузки, длительность декодирования, число React commit и записей в минуту. Проверить на физическом телефоне, если доступен.

Графика для запроса художнику после шага 3: опорные кадры походки, посадки и сна с единым якорем, еда без встроенной миски, игра без клубка, отдельный бортик лежанки при необходимости, опрокинутая премиальная миска. Для первых четырёх задач достаточно текущих ассетов.
