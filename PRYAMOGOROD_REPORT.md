## Что реализовано
- Мобильная карта: 4 района, 16 закрытых при чистом старте зданий. Первый бренд не задан заранее.
- Серверное открытие района и одного здания по первому действительному QR; индивидуальный временный intro. У последующих новых брендов meeting.
- Альбом 16 коллекций / 256 дизайнов. Имена, характеры и дизайны взяты из предоставленной Google-таблицы.
- Одноразовые случайные QR, хранение только хеша, атомарное погашение, уникальная активация, серверная награда за новый токен повторного дизайна. Старый токен не приносит наград.
- Гостевая сессия, серверные сохранения города, проверка доступа к модулям, версии сохранений и защита от устаревшей записи.
- JRPG-интерфейс реплик и ответов с серверной проверкой пути.
- Контракт модулей и совместимый адаптер прежней игры Мэйку. Локальный оригинал остаётся; создаётся отдельный прогресс пользователя, серверная копия и первоначальный резервный импорт.
- Dev-инструменты для новой отдельной тестовой игры, выбора любого первого бренда, выпуска QR/ссылки и JSON-импорта каталога. Production не регистрирует dev API и отвергает тестовые QR.

## Технологии
Существующий React / TypeScript / Vite / Zustand. Новый самостоятельный монолит Node.js / Fastify / PostgreSQL, SQL-миграции через pg. qrcode используется для тестового PNG. Новые серверы сторонних платформ не подключались.

## Ограничения и временные решения
1. В исходной таблице не заполнены районы, здания и игровые механики. Группировка по четырём брендам, названия районов 1–4 и технические здания временные; это не утверждённый лор.
2. 15 игровых механик имеют честные информационные заглушки. Полноценные сюжеты и портреты не создавались.
3. PNG для 256 стикеров пока не привязаны: карточки показывают названия и номера. Файлы художника сохранены.
4. Численные эффекты отсутствуют в источнике. Все дизайны сейчас collect, повторный дизайн — предварительный серверный параметр 10 монет. Контракт coins / moduleEvent подготовлен, конкретные реакции будущих игр не реализованы.
5. Городские монеты авторитетно ведутся сервером. Прежний огромный кошелёк Мэйку сохранён внутри модуля, автоматически в городской не переносится. Экономика самого тамагочи пока клиентская; это оговорённая граница адаптера.
6. Гостевой вход не имеет восстановления после удаления cookie или переноса на другое устройство. Cookie действует 30 дней.
7. Физическая камера не проверялась: используется браузерный BarcodeDetector. На несовместимых браузерах остаётся открытие QR-ссылки. Для смартфона вне localhost требуется HTTPS.
8. Docker Compose подготовлен, но не запускался: Docker отсутствует. Проверка сделана на отдельном локальном кластере PostgreSQL 17, без изменения существующей установленной базы.
9. Развёртывание в интернете и внешняя нагрузка не проверялись. Нужны HTTPS, реальные секреты, резервное копирование и вход пользователя.
10. Нет Git-истории, поэтому фиксация коммита/сравнение с веткой не выполнялись.
