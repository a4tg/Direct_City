# Прямогород

Существующий «Мир Мэйку-тян» расширен картой города, альбомом и самостоятельным backend. Художественные материалы остаются в исходных папках. У новой игры нет фиксированного стартового персонажа.

## Быстрый запуск

Нужны Node.js 22.12+ и PostgreSQL 17 либо Docker Compose.

```powershell
Set-Location -LiteralPath 'C:\Users\artem\Desktop\Cod(ck)ing\projects\Meiku_world'
npm.cmd install
Copy-Item .env.example .env
```

Если .env уже существует, сохраните его настройки. Заполните DATABASE_URL, APP_ORIGIN и POSTGRES_PASSWORD.

Вариант с Docker запускает только отдельную базу проекта.

```powershell
$env:POSTGRES_PASSWORD='local-dev-only'
docker compose up -d db
```

В .env пароль должен совпадать с POSTGRES_PASSWORD. Значение в примере предназначено для локальной разработки.

После запуска PostgreSQL примените схему и каталог.

```powershell
npm.cmd run db:migrate
npm.cmd run db:seed
npm.cmd run dev
```

npm run dev запускает frontend и backend вместе. Окно терминала должно оставаться открытым. Откройте http://localhost:5173. Backend слушает 127.0.0.1:3001, Vite проксирует /api. Остановить оба процесса можно Ctrl+C.

Для раздельного запуска используйте npm run dev:client и npm run dev:server в двух терминалах.

Если этот отдельный кластер остановлен, его можно запустить.

```powershell
& 'C:\Program Files\PostgreSQL\17\bin\pg_ctl.exe' -D 'C:\Users\artem\Documents\Codex\pryamogorod-work\pgdata' -l 'C:\Users\artem\Documents\Codex\pryamogorod-work\postgres.log' -o '-h 127.0.0.1 -p 55432' -w start
```

## Первая тестовая игра

Раскройте «Режим разработчика», нажмите «Начать новую тестовую игру», выберите любой бренд и дизайн. Создайте новый QR и откройте тестовую ссылку либо нажмите «Активировать этот QR». Первый QR открывает его район и здание и выбирает индивидуальное вступление. После знакомства здание доступно на карте.

Для проверки повторного дизайна создайте ещё один новый QR того же дизайна. Он добавит 10 городских монет согласно предварительному серверному параметру DUPLICATE_REWARD. Повторное использование прежнего QR вернёт ошибку без награды.

Кнопка камеры использует BarcodeDetector и getUserMedia. Нужны разрешение камеры и защищённый контекст браузера. На localhost разработка доступна. Для телефона в сети нужен HTTPS и соответствующий APP_ORIGIN. Проверенный основной сценарий этапа — тестовая ссылка. Ручной ввод промокода не является игровым сценарием.

## Мэйку и прежний прогресс

Дом Мэйку открывается через QR MeikuNeko. Адаптер копирует прежний локальный прогресс в модуль текущего пользователя, сохраняет исходный ключ и резервную серверную запись. Кошелёк Мэйку отображается внутри его приложения, городской кошелёк — в шапке Прямогорода. Мэйку продолжает использовать свои существующие награды и магазин.

Прогресс модуля автоматически сохраняется. При конфликте версий локальная копия остаётся в браузере, а панель предлагает загрузить серверную. Удалять старое сохранение для запуска города не нужно.

## Контент

server/content/catalog.json содержит названия 16 персонажей и 256 дизайнов из таблицы. sourceRef сохраняет ссылки на источник. Временными остаются распределение районов, здания, короткие сцены и экраны остальных 15 механик. Реестра готовых PNG-стикеров пока нет.

Обновить каталог можно командой npm run catalog:import -- <путь-к-json>. Структура проверяется перед атомарным импортом. Пример полной структуры — текущий catalog.json. Доступен также импорт файла в dev-панели. Существующие идентификаторы нельзя произвольно менять после выдачи QR.

## Проверки и сборка

```powershell
npm.cmd run typecheck
npm.cmd run typecheck:server
npm.cmd test
npm.cmd run build
npm.cmd run build:server
```

Серверные интеграционные тесты запускайте на отдельной базе с применённой схемой и каталогом.

```powershell
$env:DATABASE_URL='postgresql://pryamogorod:local-dev-only@127.0.0.1:55432/pryamogorod_test'
npm.cmd run db:migrate
npm.cmd run db:seed
npm.cmd run test:server
Remove-Item Env:DATABASE_URL
```

Для собранного сервера используется npm run start:server после build:server. Установите NODE_ENV=production, DEV_TOOLS=false и корректный APP_ORIGIN. Frontend dist нужно обслуживать через веб-сервер с проксированием /api на Fastify. Vite preview проверяет сборку frontend, для полного приложения требуется API-прокси.

Animation Lab остаётся отдельной dev-страницей http://localhost:5173/animation-lab/. Пользовательская навигация города её не содержит.

Подробности архитектуры — PRYAMOGOROD_ARCHITECTURE.md, результаты проверки — PRYAMOGOROD_REPORT.md.


## Мастер на все руки КЛИМЫЧ

Первый самостоятельный модуль: пять заказов, интерактивный ремонт, оценка и серверный прогресс. Войдите в открытое через QR здание КЛИМЫЧ. Перед первым запуском примените npm run db:migrate и npm run db:seed. Монеты за ремонт пока отключены. Описание, управление и результаты проверки — docs/klimych-minigame.md.


## WORLD MAP ENGINE

Главная карта использует утверждённый PNG и 16 отдельных зданий. npm run map:sync обновляет реестр из папки MAP; при npm run dev изменения PNG обнаруживаются автоматически. При сборке реестр также обновляется. MAP_SOURCE_DIR в окружении переопределяет папку художника. Если её нет, используются сохранённые ассеты проекта. Редактор доступен только в dev-режиме; его JSON применяется через npm run map:layout -- путь-к-файлу. Для утверждённой географии примените npm run db:migrate и npm run db:seed. Подробности и проверки — docs/world-map-engine.md.
